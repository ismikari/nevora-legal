# nevora-legal

Τα δημόσια νομικά κείμενα της εφαρμογής **Nevora**.

Ζουν σε **ξεχωριστό δημόσιο repo** επειδή ο κώδικας της εφαρμογής είναι ιδιωτικός,
ενώ το GitHub Pages χρειάζεται δημόσιο repo για να λειτουργήσει δωρεάν.

Το URL πρέπει να **μείνει σταθερό**: καταχωρείται στο App Store Connect και το
βλέπουν οι χρήστες από τη σελίδα της εφαρμογής. Αν αύριο μεταφερθεί σε δικό domain,
εδώ μπαίνει ανακατεύθυνση — δεν σβήνεται.

| Αρχείο | Δημόσιο URL |
|---|---|
| `index.html` | Πολιτική Απορρήτου (ελληνικά + αγγλικά) |

## Ενημέρωση

Το κείμενο συντηρείται μαζί με τον κώδικα, στο `legal/privacy-policy.html` του repo
της εφαρμογής, ώστε να αλλάζει **στο ίδιο commit** με τη λειτουργία που το επηρεάζει.
Εδώ αντιγράφεται όταν πρέπει να δημοσιευτεί.

⚠️ **Η πολιτική ενημερώνεται ΠΡΙΝ ενεργοποιηθεί οποιαδήποτε νέα συλλογή δεδομένων**
— όχι μετά. Αφορά κυρίως τους λογαριασμούς και την κοινοποίηση σε διαιτολόγο.

Σε κάθε ουσιαστική αλλαγή: νέα ημερομηνία ισχύος και νέος αριθμός έκδοσης στην κορυφή.
